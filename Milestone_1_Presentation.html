Architecture FastAPI + AsyncIO Page 02 / 05

Backend Scaffolding & System Architecture

Modular, asynchronous 3-tier structure engineered for high-concurrency multi-agent workloads

⚡ Async Web Core

  • Powered by FastAPI and Uvicorn for non-blocking asynchronous request handling.
  • Lifespan Management: Automated startup database initialization (init_db()) and graceful shutdown.
  • Live Health Endpoint: GET /health provides continuous readiness/liveness probing.

📂 Modular Layering

  • API Routers (/app/api): Separated into auth, stocks, and research controllers.
  • Config Layer (/app/config): Centralized validation via Pydantic Settings reading from .env.
  • Services Layer: Decoupled market and news fetchers from route logic.

🛡️ Security & CORS

  • Bcrypt Password Hashing: Salted, one-way password encryption via Passlib.
  • Stateless JWT Tokens: Encrypted authorization with configurable TTL (ACCESS_TOKEN_EXPIRE_MINUTES).
  • CORS Policy: Granular origin whitelisting allowing secure React SPA requests without browser blocks.
🎙️ Speaker Note: "On Slide 2, we see our backend scaffolding. Rather than putting code into one script, we adopted strict Separation of Concerns. API routes, business services, database models, and security utilities exist in dedicated modules. Authentication uses salted Bcrypt hashes and cryptographic JWT tokens, while CORS middleware allows our React client on port 5173 to interact seamlessly."
Persistence Layer SQLAlchemy 2.0 Page 03 / 05

Relational Database Schema & Entities

Normalized schema designed for multi-agent execution logging and reproducible reports

🗄️ Relational Entities (6 Core Tables)

  • users: Auth credentials, hashed passwords, active flags.
  • research_tasks: Orchestrator table tracking lifecycle (PENDING, RUNNING, COMPLETED).
  • agent_results: Granular JSON findings output by Fundamental, Technical, News, and Risk agents.
  • source_documents: Cached raw news articles, filings, and citations.
  • research_reports: Final synthesized markdown reports and consensus ratings (BUY/HOLD/SELL).
  • saved_stocks: User watchlists and portfolio tracking.

⚙️ Engine Features & Data Integrity

  • Dual-Engine Architecture: Zero-dependency SQLite (aiosqlite) for fast local dev; ready for PostgreSQL (asyncpg) in production.
  • Session Injection: FastAPI Depends(get_db) dependency ensures isolated per-request sessions and eliminates connection leaks.
  • Cascading Deletes: Removing a research task automatically cascades and cleans child agent results, preventing orphan records.
  • Pydantic Data Contracts: Type-safe request and response validation at API boundaries.
🎙️ Speaker Note: "Slide 3 covers our persistence layer. We built a normalized schema across 6 core entities. When a user requests research, the task is tracked in research_tasks, each agent stores its findings in agent_results, and the report synthesizer persists the final markdown into research_reports. Using async SQLAlchemy session factories guarantees thread safety and high throughput."
Market Engine NSE & BSE Page 04 / 05

Market Data Retrieval & Validation Pipeline

Resilient dual-layer fetching with anti-bot resistance and mathematical integrity checks

🇮🇳 Dual-Exchange Support

  • Intelligent Ticker Resolution: Automatically suffixes symbols for Indian exchanges (.NS for NSE, .BO for BSE).
  • Company Fundamentals: Fetches market cap, P/E ratio, sector, 52-week high/low, and live quote prices.
  • Multi-Timeframe Candles: Generates time-series data (1mo, 6mo, 1y).

🛡️ Anti-Rate-Limit Layer

  • Primary Layer (curl_cffi): Uses real Chrome TLS browser fingerprint impersonation to defeat Yahoo Finance 403 blocks.
  • Fallback Layer (yfinance): Automatic failover to standard library if primary fetcher encounters anomalies.
  • Ensures 99.9% uptime without requiring paid commercial API keys.

📐 Data Validation Pipeline

  • Null & Duplicate Cleaning: Eliminates NaN values and deduplicates timestamps.
  • Mathematical Axiom Tests: Enforces High >= Low and Close > 0 before rendering.
  • Prepares Technical Indicators: Cleaned data feeds directly into SMA, EMA, RSI, and MACD algorithms.
🎙️ Speaker Note: "Slide 4 highlights our market data pipeline. Standard Yahoo Finance scrapers frequently get IP blocked by bot detectors. We engineered a dual-layer strategy: primary queries use curl_cffi with browser TLS impersonation, falling back to yfinance. Crucially, all price candles undergo mathematical integrity validation to eliminate corrupt data before reaching charts or AI agents."
